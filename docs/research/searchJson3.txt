### 🔍 Deeper Analysis: The `reddit-playlists` Data Pipeline
The `reddit-playlists` project is an excellent blueprint for the automation pipeline you're building . Its flow maps directly to your visions:
1.  **Data Collection**: It scrapes track submissions from music subreddits using the **PRAW** library for the Reddit API.
2.  **Data Structuring & Storage**: Extracted data (artist, track, subreddit) is organized and stored in **JSON configuration files**.
3.  **Processing & Action**: A core script parses the submissions, matches them against **Spotify's API** (using Spotipy), and creates/updates playlists automatically .
4.  **Automation**: The entire process is scheduled to run weekly using **GitHub Actions**.

For your addon, you would replace "Reddit" with "local file scanner" or "YouTube API," and "Spotify" with "Kodi library," but the **architectural pattern is identical**.

### 💡 Recommended Development Path
To start building, I suggest a focused approach:
1.  **Foundation**: Use the **`library` toolkit**  or a simple script with `ffprobe` to scan your local videos and output a consistent JSON list with hashes, titles, and file paths.
2.  **Online Data**: Use or adapt a **YouTube scraper**  to get JSON metadata for the online videos you want to compare against.
3.  **Core Logic**: Employ a **`json-compare`** library  to match titles and hashes between your two JSON lists. Integrate the scoring logic from **`plex_dupefinder`**  to decide match quality.
4.  **Action**: Write the final script to generate Kodi `strm` files pointing to online streams, replacing the local files your logic deems inferior.
