## 🔁 Workflow (Local Only)

1. **Edit** – work inside `projects/plugin.program.*/`
2. **Script** – run from `scripts/`:
   - `lint.sh` – ruff check
   - `bundle.sh` – create zip in `/zips/`
   - `tree.sh` – generate directory tree
3. **Build** – outputs → `/zips/`
4. **Log** – activity → `/logs/`

All scripts are idempotent and minimal.

## 🧱 Architecture Blueprint

We follow **strict one‑way dependency flow**:

```
Entry points → Modules → Core libraries
```

- **Core** never imports modules.  
- **Modules** declare dependencies explicitly.  
- **Settings** control everything at runtime.

**Deletion test:** remove any module folder → rest of addon still works.
