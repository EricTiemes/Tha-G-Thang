✅ Three levels of "finding useful scripts"

1. Search your own device

```bash
find /storage/emulated/0 -name "*.sh" 2>/dev/null
find ~ -name "*.py" 2>/dev/null
grep -r "ollama" ~/ 2>/dev/null
```

What you'll find:

· Old scripts you forgot about
· Termux tools you installed
· Ollama helpers others shared

2. Download from GitHub (Termux-optimized)

```bash
# Example: Ollama chat scripts
git clone https://github.com/ggml-org/llama.cpp
git clone https://github.com/termux/termux-packages
```

Then search inside:

```bash
find llama.cpp -name "*.sh" -o -name "*.py"
```

3. Use curl to fetch single scripts from the web

```bash
# Example: A script to query your specialists
curl -O https://raw.githubusercontent.com/user/repo/main/query_specialist.sh
chmod +x query_specialist.sh
```

✅ TODO1 – Chat with Specialists Script

Goal: Select a specialist YAML file → extract system prompt → start Ollama chat.

File: ~/Tha-G-Thang/scripts/chat.sh

```bash
#!/usr/bin/env bash

SPECIALIST_DIR="$HOME/Tha-G-Thang/ai/specialists"
MODEL="phi3:mini"

# 1. Pick a specialist
cd "$SPECIALIST_DIR" || exit 1
file=$(ls *.yaml | fzf --prompt="🧠 Pick a specialist: ") || exit 1

# 2. Extract system prompt
prompt=$(yq '.system_prompt' "$file" | sed 's/^"//;s/"$//')

# 3. Clear screen and start chat
clear
echo "📁 $file"
echo "🧠 $MODEL"
echo "────────────────────"
echo ""

# 4. Launch Ollama with system prompt
ollama run "$MODEL" --system "$prompt"
```
